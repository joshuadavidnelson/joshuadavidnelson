# Hi, I'm Josh 👋

One-time award-winning mead-maker, full-time engineer, and steadfast Oxford Comma user.

I build mostly WordPress things, and other web stuff sometimes, from Seattle. I run Hand Forged Web, LLC, and I maintain a handful of open-source WordPress plugins in my spare time.

## 🔌 Plugins I maintain

| Plugin | What it does |
| ------ | ------------ |
| [Disable Blog](https://github.com/joshuadavidnelson/disable-blog) | All the power of WordPress, without a blog. Removes blog-related functionality. |
| [Archived Post Status](https://github.com/joshuadavidnelson/archived-post-status) | Archive posts and pages so you can unpublish content without trashing it. |
| [Scripts To Footer](https://github.com/joshuadavidnelson/scripts-to-footer) | Moves scripts to the footer for faster perceived page loads, with options to keep specific scripts in the header. |

Bug reports and pull requests are welcome. Each repository's README has its contribution and support details.
